# 机甲与坦克的随机入池

每次开始整套抽取时，先做一次 20% 概率的共同入池判定。成功时，机甲与坦克均可参与后续抽取；失败时，随机候选池去掉这些装备。入池不保证抽中，最终出现率也不等于 20%。

范围按目录中的 `vehicle_exo_` 和 `vehicle_td_` ID 识别，目前包括四台机甲（EXO-45、EXO-49、EXO-51、EXO-55）和两台坦克（TD-110、TD-220）。M-102 侦察车、M-103 补给车仍在普通池，不受此判定影响。

M-102 侦察车与 M-103 补给车互斥，两款坦克 TD-110 与 TD-220 也互斥：初始纯随机、平衡抽取、局部修复、锁定及输出后随机/手动换装均遵守各类最多一台；原槽位可以切换同类另一台。侦察/补给车仍在普通池，坦克仍受20%入池判定影响。可以同时携带一台机甲、一台坦克、一台侦察或补给车。普通支援武器/背包的输出后换装豁免保持不变。

- 判定只发生在 `beginAssessmentDraw`；内部整套重抽、七槽局部修复、小空间枚举、暂停恢复共用已经确定的候选池，不能反复尝试入池。
- 初始纯随机和平衡抽取使用同一规则。保留现有解锁、排除、互斥限制；机甲、坦克及侦察/补给车各类始终最多一台。
- 显式锁定的机甲/坦克继续保留；关池时只有这些锁定项保留，其他车辆不能进入空槽。排除或未解锁项不能通过锁定绕过原有检查。
- 关池后剩余战备不足四件时，结束为 `EMPTY_SLOT_POOL`，原因 `ARMORED_POOL_CLOSED`；不自行再次判定。用户重新发起一次整套抽取才产生新判定。
- 输出后的随机换装/人工点选不重新检验评分，也不受初始入池判定约束；各类载具最多一台的限制始终有效。
- 不改评分、六维及格线、物理资源检查或黑箱输出。网页和 Bot 共用同一 `draw.mjs`，Bot 固定整套运行文件的提交和哈希。

实现使用现有随机数生成器的无偏 `uniformInt(5) === 0`。相同种子和相同输入可复现；新增一步随机判定后，不承诺与旧版本的同种子输出一致。
