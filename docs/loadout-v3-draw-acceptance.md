# 七槽抽取验收

入口：[战术搭配器](../HD2_Wiki/loadout.html)。本机预览使用 http://127.0.0.1:8791/HD2_Wiki/loadout.html 。

- 点「新版平衡抽取」，一次抽完整七件，未通过继续抽，首次通过当前规则即输出。不会挑最高分，也不排除强配装。
- 实际抽取为通用配装入口：没有场景选择，不展示六维分数、详情、种子、模型版本或解释按钮。后台照常判断，界面只给装备结果。
- 任何操作都最多携带一台机甲，包括整套抽取、随机换一件和人工点选；已有机甲可以换成另一台。
- 初次整套抽取检查普通支援武器与背包的占位。C4背包同时占用支援武器位与背包位，不能与另一件常驻支援武器或普通背包同时抽出。一次性武器、B-100地狱火背包不占这些互斥名额。子弹风暴按用户指定算普通支援武器，不能使用一次性豁免。
- 随机换一件和人工点选不再检查能力或其他装备互斥，保留机甲上限、槽位类型、不重复选同一件、锁定及候选池设置。自由换装后可以形成其他占位冲突组合；带冲突锁定重新整抽仍会提示解除锁定。
- 人工修改单件评分后，点「重新加载资料」再抽；单件校准页独立保留。
- 锁定或排除导致的小池无通过结果会直接提示；大池搜索可暂停、取消，不会拿资料不足的结果冒充通过。

当前为本地验收版，使用assessment-v2已有数据与人工校准。运行时是浏览器本地JavaScript，不需要大模型。通过代表已建模条件满足，实战手感、未覆盖机制与模型参数仍接受后续反馈；没有宣称游戏实测认证。

内部依然使用现有伤害、库存和敌人样本基准；删除场景选项没有伪造全阵营实测覆盖。当前分数及物理检查政策不因界面黑箱化而改变。

复核记录见[实际页面测试结果](ai/assessment-draw-mech-limit-20261028/ui-result.json)。抽取与替换的自动化测试为`scripts/tests/loadout-v3-assessment-v2/draw*.test.mjs`；真实页面复核脚本为`scripts/check-assessment-draw-ui.mjs`，只读当前模型，不写人工评分文件。旧版截图保留为历史记录，不代表当前页面。
