## 1. 数据架构总览

### 数据流

```
官方游戏 API (api.live.prod.thehelldiversgame.com)
  │
  ├─ GitHub Actions 每 5 分钟（fetch-data.yml）
  │    → scripts/fetch_site_data.py 抓取 + 合并翻译 + 落盘
  │    → HD2-Galatic_war-Map/data.json（主数据，约 300KB）
  │    → HD2-Galatic_war-Map/data/recent/（实测帧，15 分钟粒度）
  │
  ├─ 翻译仓库（HD2Web-Trans，每 15 分钟）
  │    → 官方 zh-Hans API 采集新闻/MO/事件正文
  │    → 缺官中时 DeepSeek 机翻兜底
  │    → 推送 TransNews.json 到本仓 data/translated/
  │    → 触发本仓 merge_translations.py 合并进 data.json
  │
  ├─ 星球历史仓库（hd2-planet-history，每 15 分钟）
  │    → 记录全部 273 颗星球的 {players, health, owner}
  │    → 24h 滚动窗口，GitHub Pages 供星球详情页 fetch
  │
  └─ API Schema Watch（每天 2 次，UTC 22:00 / 10:00）
       → 比对 8 个信息源的 schema（字段名+类型）
       → 有变更开 Issue 报告 + 更新基线
```

### 页面数据源优先级

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | `data.json` | 主数据，CI 每 5 分钟更新 |
| 2 | `data/recent/` 实测帧 | 15 分钟粒度差分（解放速率/MO 速率） |
| 3 | `data/translated/` | 翻译仓库产物（TransNews / official_texts / campaign_zh） |
| 4 | `tables/` 静态表 | 星图/区域/补给线/词条/效果对照表 |
| 5 | `hd2-planet-history` | 单星球人数/血量历史（24h 窗口） |
| 6 | 官方 API 直连 | 最后兜底（口径可能与主站不一致） |

## 2. 战况主数据（data.json）

**生成**：`scripts/fetch_site_data.py`，GitHub Actions `fetch-data.yml` 每 5 分钟。

**来源**：官方 `api.live.prod.thehelldiversgame.com`（需 `X-Super-Client` 头），companion 兜底。

**关键字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `fetchedAt` | str ISO | 抓取时刻（页面时间基准） |
| `planets[]` | array | 273 颗星球：index/name/sector/currentOwner/health/maxHealth/players/resistance/activeEffects/regions |
| `campaigns[]` | array | 当前战役：liberation（planet.health→解放度）/ defense（defendersProgress/attackersProgress/attackersRate/remainingTime） |
| `assignments` | dict | 当前 MO：briefing/tasks/progress/deadline/startedAt |
| `dispatches[]` | array | 30 条原始新闻（英文） |
| `news[]` | array | 最新 10 条（带翻译仓库中文译文） |
| `major_order` | dict | MO 简报：brief/translated_brief/translated_at |
| `dss` | dict | DSS：planetIndex/activeEffectIds/tacticalActions（含捐献进度）/electionEnd |
| `player_distribution` | dict | total/humans/terminids/automatons/illuminate |
| `ownership_history` | dict | events/defenseEvents（归属变化检测） |
| `active_campaign` | dict | 战役剧情（title_cn/description_cn/phases 中文） |
| `strategic` | dict | 战略机遇：active/status_cn/dispatch_id |
| `impactMultiplier` | float | 解放速率推演用影响系数 |

**翻译字段解耦**：`fetch_site_data.py` 不覆盖 `news`/`major_order`/`strategic`——这三个字段由翻译仓库通过 `merge_translations.py` 单一写入。

## 3. 重要指令（Major Order）

### 数据来源
- 进度：`data.json → assignments`（官方 API `v2/Assignment/War/801`）
- 中文简报：`major_order.translated_brief`（翻译仓库官方 zh-Hans 采集）
- 限定装备：`major_order.tasks`（按 `setting.tasks[].valueTypes` 解析：1=阵营、3=数量、5=装备 ID）

### 任务预测口径（`js/forecast.js`）

```
rate = current / 全程已历小时
projected = clamp((current + rate × 剩余小时) / goal × 100, 0, 100)
etaH = (goal - current) / rate
win = etaH ≤ remainingH
```

- 速率来源优先级：实测帧全程均速 → 近 1 小时实测 → 推演均速
- type 11（占领标记）不做线性外推（进度是 0/1 跳变）
- type 13（驻守）只判当前是否满足条件

### 装备限定（限定装备官中名）

```
setting.tasks[].values[5]（装备 ID）
  → scripts/order_items_en.json（社区提取的官方英文串）
  → 站点图鉴 terms.json（官方简中名）
  → en_fallback（明确标记英文名回退）
  → unresolved（只保留 raw ID，不猜名）
```

## 4. 星球详情页（星球指挥台）

**文件**：`HD2-Galatic_war-Map/planet.html`

### 信息架构（桌面 ≥1280px 三栏指挥台）

```
┌─────────────────── Command Hero（全宽）───────────────────┐
│  左：身份          中：168px 解放进度环      右：Quick Intel │
│  （中/英/序号/      （aria-label + 文本值）    （在线/占比/   │
│   星区/归属/状态）                                  净速率/…）│
├──────────────┬──────────────────────┬──────────────────────┤
│ 左 4 栏       │ 中 5 栏               │ 右 3 栏              │
│ 战略态势      │ 星球趋势（主图）       │ 星球统计              │
│ 补给线        │ 下属区域              │ （13 张 KPI 卡）     │
├──────────────┴──────────────────────┴──────────────────────┤
│ 环境与作战参数（全宽）                                        │
├──────────────────────────────────────────────────────────────┤
│ 数据口径（折叠 details）                                      │
└──────────────────────────────────────────────────────────────┘
```

### 关键公式（与星图完全一致）

| 公式 | 表达式 | 说明 |
|---|---|---|
| 解放进度 | `1 − health / maxHealth` | 己方星球按 100% 显示（官方报满血） |
| 推演速率 | `在线玩家 × impactMultiplier × LIB_RATE_K ÷ 血量 − 抵抗度` | LIB_RATE_K = 90 |
| 等效推进速率 | `净速率 × 血量倍数`（基准球=100 万血） | 让"血厚"折回百分比体感 |
| 抵抗度 | `regenPerSecond / maxHealth × 100` (%/h) | |
| 每小时回血 | `抵抗度% × maxHealth / 100` (HP/h) | 推演口径绝对值 |

### 词条权威链

```
hd2_variables.json（行动变量表，82 个 effect id，中文名+描述+分组）
  → galactic_effects.json（description_cn 官方中文 + description 英文）
  → effect_id_cn.json（中文名兜底，191 条）
  → 效果 #原始ID（照实显示，不猜名）
```

占位符替换（`fillEffectTemplate`，共享模块 `js/planet-card-effects.js`）：
- `#V_ONE` 配备名类（ARSENAL AUGMENTATION）→ 确定性替换为 `stratagems_full` 站内中文名
- `#V_ONE/#V_TWO/#AMOUNT` 数值类 → 查 `tables/effect_values.json`（galacticWarEffects 309 条）替换实值
- 槽位为 0 → `[动态值]` 标注（不猜）

### 词条分组

保留分组：变种类（终结族变种/特殊个体/机器人军团/…）+ 作战限制。
其余（深域惧像/环境条件/设施与场所等）不分组平铺底部。

### 单星球趋势图

数据来自 `hd2-planet-history` 仓库（GitHub Pages）：
- 双轴折线：左轴=在线人数（蓝实线），右轴=解放度（黄虚线）
- hover 十字线 + tooltip（时间/人数/解放度/HP/归属）
- 无历史时退回全服分布趋势

## 6. 下属区域（城市 / 超大型工厂）

**数据源**：
- 静态表 `tables/planet_regions.json`（84 颗有城市/工厂的星球，来自 wiki Lua 模块）
- 中文名 `tables/planet_regions_zh.json`（游戏内文本解包的官方简中）
- 运行时 `data.json → planets[].regions[]`（官方实时数据）

**区域速率**：实测优先（`data/recent/planet_regions.json` 帧差分），推演兜底（区域玩家 × impactMultiplier × K ÷ 区域血量 − 区域抵抗度）。

**区域规则**（`js/regions.js`）：
- 开放条件 = `入侵进度 ≥ (1 − availabilityFactor) × 100` 或 `主星球解放 ≥ 阈值`
- 解放贡献 = `区域满血 × damageMultiplier / 母星球血池 × 100`（个百分点）

## 7. 解放速率与实测帧

**实测优先、推演兜底**——全站统一口径。

### 实测帧

- 来源：`data/recent/`（CDN 15 分钟一帧，由采集脚本落盘）
- 文件：`index.json`（清单）、`planet_<idx>.json`（单星球血量帧）、`assignments.json`（MO 进度帧）、`planet_regions.json`（区域帧）
- **断更保护**：清单生成时间超 3 小时 → 整块停用实测，自动回退推演

### 差分公式

```
实测净推进 %/h = −(末帧血量 − 首帧血量) ÷ 满血 × 100 ÷ 帧间隔小时
施加 / 纯产出   = 实测净推进 + 抵抗度
等效抵抗度     = regenPerSecond × 3600 ÷ 1,000,000 × 100（100 万血基准）
```

**满血顶格拒绝**：窗口首尾帧都 ≥ 满血（容差 0.05%）时不产出实测（Δ=0 不代表净速率为 0，必须交推演兜底）。

**易主拒绝**：窗口内星球归属发生变化时不产出实测。

## 8. DSS 民主空间站

**数据源**：`data.json → dss`（官方 `spaceStations` + `tacticalActions`）

**捐献进度**（`js/dss-donations.js` 口径）：
- 进度 = `cost[0].current / cost[0].target × 100`（只在筹集期展示）
- 资源映射：`itemMixId` → 普通样本/稀有样本/申购点
- 每人限额 = `maxDonation` / `maxDonationPeriodSec`

**生效效果**：`activeEffectIds` → 对照表（`HD2行动变量对照表.md` TACTICAL ACTION 段）→ 中文名 + 描述

## 9. 全服趋势与单星球趋势

### 全服趋势（主面板 index.html）

- 渲染：原生 canvas 双轴折线 + hover 十字线 + tooltip

## 10. 星图归属变化

**数据源**：`data.json → ownership_history`

**字段**：
- `events[]`：归属变化事件（`detectedAt / planetIndex / fromOwner / toOwner / previousSeenAt`）
- `defenseEvents[]`：防守成功事件（`detectedAt / planetIndex / attacker`）

**展示**（`js/ownership-changes.js`）：
- 按时间窗口（24h / 48h / 7d）筛选
- 星球聚合：多场变化串成链（如 超级地球→终结族→超级地球）
- `previousSeenAt` 早于窗口起点 → 标注「范围待确认」
- 覆盖率：标注实际覆盖时长（数据积累中可能不满窗口）

## 13. 弹道模拟器

**文件**：`HD2_Ballistics/`（纯前端离线，无第三方依赖）

**作者**：[@Darctor](https://github.com/Darctor) · [哔哩哔哩](https://space.bilibili.com/300385406)

**物理模型**（`ballistics.js`）：
- 各向同性二次空气阻力：`a_drag = -K·|v|·v`，`K = 0.5·ρ·Cd·A/m`
- 恒定重力（可乘 gravity_multiplier）
- 伤害公式：`伤害比例 = 25% + 75%·(v/v_config)²`
- 速度继承：发射者移动矢量按世界坐标（X前/Y上/Z右）合成到出膛初速

**武器目录**（`HD2_Ballistics/data/equipment_catalog.json`）：
- 上游来源：`Darctor/Helldivers2_RawData`（按 HEAD SHA 绑定 URL）
- 同步频率：每天（`sync-ballistics-catalog.yml`）
- 关联规则：Wiki 装备名 → PWC 组件名（精确归一→标点归一）→ 射弹（组件直配→伤害+数值确定性搜索）

**预算上限**：MAX_TOTAL_STEPS=250000（积分步数）、MAX_ANGLE_SAMPLES=3600（扫描采样数），超限直接报错。

## 14. 翻译链路（HD2Web-Trans）

**独立仓库**（私密）：`Jerry114514/HD2Web-Trans`

**主同步频率**：每 15 分钟（cron `*/15`）

**数据流**：
```
官方 API zh-Hans（新闻/MO/事件正文）
  → 官中缺失时 DeepSeek 机翻兜底
  → TransNews.json / official_texts.json
  → repository_dispatch 触发 Push TransNews to Page
  → merge_push_page.py 合并进主仓 data.json
  → Pages 重建
```

**合并优先级**：人工译文（manual:true）> 官方中文（official_zh）> 机翻（machine_translation）> 英文原文（official_untranslated）

## 数据真实性边界

- 缺失数据显示「—」「暂无区域数据」「尚未接入」，**不得填入示例值**
- 未收录 effect id 照实显示原始编号，**不猜测名称**
- 槽位为 0 的效果数值保持 `[动态值]` 标注，**不猜值**
- 击杀按星球累计不按阵营归属，照实呈现不修正
- 「命中率 > 100%」是官方原始数据特征，照实呈现不修正
- 全服趋势**不是**单星球历史，页面明确标注
